# Network Traffic Analyzer

A practical network traffic analysis tool built with Python and Scapy on Kali Linux.

## Features

- Captures network packets from the loopback interface
- Counts captured IP packets
- Identifies common protocols
- Tracks source IP addresses
- Tracks destination IP addresses
- Displays top source and destination IPs
- Generates an automatic traffic analysis report

## Technologies Used

- Python 3
- Scapy
- Kali Linux
- Linux Terminal
